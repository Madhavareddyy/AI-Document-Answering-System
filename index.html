    How it works

    1. Reads a plain-text document and splits it into sentences.
    2. Stores sentences as facts in a knowledge base.
    3. Removes common stop words from each question.
    4. Uses keyword matching and IDF-style scoring to rank facts.
    5. Returns the highest-ranked sentence and classifies the question type.

    Project scope: Traditional rule-based retrieval only. No LLM, embeddings, external API or RAG is used.
